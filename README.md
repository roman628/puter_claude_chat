# Puter Claude Chat

**Live site:** https://roman628.github.io/puter_claude_chat/

A single-file HTML chat app for talking to Claude (and other LLMs) for free via [Puter.js](https://puter.com/) — no API keys, no backend. Users sign in with their own Puter account and cover their own usage.

## Features

- Chat with Claude Opus 4.7, Sonnet 4.6, and other Claude/GPT/DeepSeek/Gemini models
- Streaming responses with live Markdown rendering
- Multiple chats stored locally in the browser, with per-chat delete and delete-all
- Image attachments for vision-capable models
- Monthly usage meter
